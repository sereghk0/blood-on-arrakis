# Кровь на Арракисе — Pocket Grimoire

Файлы:
- `krov_na_arrakise_pocket_grimoire.json` — сценарий для Pocket Grimoire.
- `icons/` — 26 круглых PNG 512×512 с прозрачным фоном.

После публикации репозитория ссылки на изображения в JSON используют:
`https://raw.githubusercontent.com/sereghk0/blood-on-arrakis/main/icons/...`

## Загрузка в GitHub

Распакуйте содержимое архива в локальную папку репозитория `blood-on-arrakis`, затем:

```bash
git add .
git commit -m "Add Blood on Arrakis Pocket Grimoire script and icons"
git push origin main
```

После push импортируйте `krov_na_arrakise_pocket_grimoire.json` в Pocket Grimoire.
