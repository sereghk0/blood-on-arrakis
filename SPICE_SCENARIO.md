# Кровь на Арракисе — Пряность v1.0

Техническая памятка Рассказчику для варианта сценария с Пряностью.

## 1. Глобальное правило Пряности

- Пряность усиливает следующее фактическое срабатывание способности персонажа.
- Если персонаж уже усилен, новая Пряность ничего не добавляет.
- Если способность не сработала, Пряность сохраняется.
- После фактического усиленного срабатывания Пряность снимается.
- Пряность сама по себе не снимает пьянство или уже действующий яд, не пробивает защиту от смерти и не отменяет регистрацию Фенринга.
- Правдивая информация учитывает текущую регистрацию персонажа.
- Пряность не возвращает уже потраченную одноразовую способность.

## 2. Источники Пряности

Всего 5 источников: 4 добрых и 1 злой.

- **Гурни Халлек** — ночью выбирает уникальную первую цель и второго игрока. Если первая цель завтра номинирует злого, второй получает скрытую Пряность. Гурни результат не узнаёт.
- **Лиет-Кайнс** — ночью выбирает двух, указывает предполагаемого злого, затем третьего. Если прогноз верен, третий получает скрытую Пряность. Кайнс результат не узнаёт.
- **Алия** — ночью прогнозирует, будет ли хотя бы один казнённый сегодня злым, и выбирает получателя. При верном прогнозе тот получает Пряность. Без казни прогноз неверен.
- **Доктор Юэ** — защищает выбранного игрока; один его живой сосед может умереть, другой получает Пряность.
- **Питер де Врис** — добрую цель травит, Приспешника или Демона усиливает Пряностью.

## 3. Усиления персонажей

### Горожане

- **Пол Атрейдес** — вместо одной проверки выбирает двух игроков и сравнивает каждого с предыдущей целью. Второй становится новой предыдущей целью.
- **Леди Джессика** — дополнительно после успешного усиленного срабатывания её нельзя отравить до следующего заката. Уже действующий яд не снимается.
- **Чани** — вместо защиты только от Демона защищает выбранного от любой смерти этой ночью.
- **Стилгар** — если первые двое одной команды, выбирает третьего и узнаёт, одной ли он команды с первым.
- **Дункан Айдахо** — может спасти до двух других игроков. Если сам должен умереть к моменту своего хода, не действует.
- **Гурни Халлек** — дополнительного усиления нет.
- **Суфир Хават** — дополнительно узнаёт один присутствующий среди выбранной тройки тип персонажа; тип выбирает Рассказчик.
- **Доктор Юэ** — дополнительного усиления нет.
- **Герцог Лето** — если по его суду казнён злой, одноразовая способность обновляется; повторно в тот же день использовать нельзя.
- **Алия** — дополнительного усиления нет.
- **Лиет-Кайнс** — дополнительного усиления нет.
- **Преподобная Мать Рамалло** — при злой цели узнаёт её настоящего персонажа вместо ложного.
- **Джамис** — выбранный после его казни игрок защищён от любой смерти этой ночью.
- **Хара** — выбранный мёртвый дополнительно может номинировать как живой.
- **Ланвиль** — пьянство Приспешника длится до следующего заката.

### Изгои

- **Принцесса Ирулан** — вместо да/нет узнаёт точное число злых среди двух целей: 0, 1 или 2.
- **Граф Фенринг** — при первой замене смерти сам выбирает, какой живой сосед может умереть вместо него.
- **Шадоут Мэйпс** — получает обязательную правду; злая цель всё равно узнаёт, что была выбрана.
- **Контрабандист Туек** — если выбранная цель действительно умерла, оба её живых соседа пьяны до следующего заката.

### Приспешники

- **Фейд-Раута** — если условие ловушки выполнено, выбранный добрый умирает; защита всё ещё может его спасти.
- **Питер де Врис** — дополнительного усиления нет.
- **Преподобная Мать Мохиам** — первый голос цели считается, все последующие голоса этого дня не учитываются; после успешного усиленного срабатывания Мохиам нельзя отравить до следующего заката.
- **Марго Фенринг** — после успешного приватного разговора цель дополнительно может умереть этой ночью.

### Демоны

- **Барон Владимир Харконнен** — дополнительно выбирает игрока, который может быть отравлен до следующего заката.
- **Император Шаддам IV** — новый указ требует казнить 2 из 3 объявленных игроков. После первой такой казни день не заканчивается. Если казнено меньше двух, указ не выполнен.
- **Шай-Хулуд** — не усиливается Пряностью.

## 4. Важные дневные взаимодействия

- Если действует указ Шаддама, Лето может объявить суд только над одним из игроков указа.
- При усиленном указе Шаддама первая казнь не завершает день; город получает возможность провести вторую.
- Шаддам считает факт казни, а не фактическую смерть. Поэтому казнённый Фенринг засчитывается даже при замене своей смерти.
- Алия проверяет всех казнённых за день.
- Ланвиль срабатывает, если Приспешник не казнён в результате конкретной номинации Ланвиля.
- Джамис срабатывает по факту своей казни, независимо от того, произошла ли затем его фактическая смерть.
- Гурни и Лиет-Кайнс не получают подтверждения успешности своих проверок.

## 5. Смерти и защиты

- Обычная Чани защищает только от смертей, вызванных Демоном.
- Усиленная Чани и Юэ защищают от любой смерти в течение ночи.
- Защита действует на весь указанный период, а не только на первую попытку смерти.
- Фенринг заменяет смерть до Дункана.
- Если смерть Фенринга уже переведена на соседа, способность считается использованной, даже если сосед затем спасён.
- Дункан не может спасти себя. Если сам должен умереть к моменту своего срабатывания, он не просыпается и никого не спасает.
- Туек реагирует только на окончательную смерть после действий Дункана.
- Хара видит только окончательный список умерших и действует последней.

## 8. Моменты расходования Пряности

- Усиление снимается только при фактическом усиленном срабатывании.
- Для Чани это момент постановки усиленной защиты.
- Для Стилгара — усиленная проверка первых двух, даже если третьего выбора не будет.
- Для Фейда — момент, когда ловушка реально дошла до условия ночной смерти.
- Для Фенринга — реальная замена смерти.
- Для Мохиам — первое голосование выбранной цели при первой номинации.
- Для Марго — успешный приватный разговор.
- Для Шаддама — создание нового усиленного указа.
- Для Дункана — только если он сам не должен умереть и реально получает усиленное срабатывание.
- Для Туека — только если его цель действительно умерла.
