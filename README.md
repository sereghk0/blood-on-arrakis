# Кровь на Арракисе — Pocket Grimoire

## Сценарии для импорта

- `krov_na_arrakise_pocket_grimoire.json` — базовая версия «Крови на Арракисе».
- `krov_na_arrakise_spice_pocket_grimoire.json` — версия с механикой Пряности.
- `SPICE_SCENARIO.md` — памятка Рассказчику: источники Пряности, усиления, порядок ночи и взаимодействия.

Оба JSON-файла используют одни и те же аватары из `icons/`.

## Аватары

`icons/` — 26 круглых PNG 340×340 с прозрачным фоном.

После публикации репозитория ссылки на изображения в JSON используют:
`https://raw.githubusercontent.com/sereghk0/blood-on-arrakis/main/icons/...`

## Импорт в Pocket Grimoire

Скачайте нужный JSON-файл из репозитория и импортируйте его в Pocket Grimoire. Для базовой игры выберите `krov_na_arrakise_pocket_grimoire.json`, для игры с Пряностью — `krov_na_arrakise_spice_pocket_grimoire.json`.
